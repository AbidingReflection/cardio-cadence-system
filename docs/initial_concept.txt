Cardio Workout Protocol Designer
    - Activity Type
        - Define activity specific variables
            - Examples:
                - Treadmill
                    - Speed (MPH)
                    - Incline  (%)
                - Stationary Bike
                    - RPM
                    - Resistance
                - Elliptical
                    - RPM
                    - Resistance
                - Ergo-meter (Rowing Machine)
                    - Drag Factor (Load but always constant)
                    - Strokes Per Min (SPM)

        - Define machine specific relative work metric function in terms of activity variables.
            - Experimentally derived through several well defined experimental sessions covering likely domain of activity specific parameters.
            - Activity variables proportionally combined to create basis parameter for polynomial regression
            - Gives the ability to graph cumulative calorie total (Position) based on a series of workout protocol Activity->Blocks.
            - Also gives ability to derive Instantaneous calories per unit time (velocity) and visualize how relative effort is likely to change over course of a session.
                - Example: Aqua Center True Elliptical
                    kCal =(0.0572 + 0.00014*(RPM*Resistance) + 0.000000285*(RPM*Resistance)^2 + -0.000000000143*(RPM*Resistance)^3)*(Duration secs)
                    - Experimentally found to be 0.13% error over a dynamic 75 min session covering full calibration domain (1.4kcal error for a 980kcal session).
            - Perhaps this can be retroactively deduced through workout sessions?  The issue is that this requires very accurate measurements over the course of a session.  Likely not viable for a "standard" user.  My first attempts yielded non continuous curves especially at low cal/sec input variables due to taking readings at predefined time intervals.  Follow-up attempts allowed the time intervals to be dynamic waiting for clean integer changes in the machine's cal workout display.   Perhaps an equipment calibration protocol can be defined constructing a printout for taking such readings, but would likely be highly dependant on user's adherence to target variable thresholds.

    - Protocol Design
        - Main components
            - Workout Protocol
                - Full series of phases constituting a planned cardio workout
            - Phase
                - A logically grouped series of workout blocks
                - Examples:
                    - Warm-up
                    - Primary
                    - Cool-down
            - Block
                - Discrete portion of a workout phase governed by a well defined cadence progression function
            - Cadence Progression Function
                - A Function that defines how the cadence variable of a given block will change over that block's duration
                - Examples:
                    - Steady
                    - Constant
                    - Stepwise
                    - Ease-In
                    - Ease-Out
            - Cadence Cycle
                - Akin to a video or audio frame
                - Smallest unit of a workout
            - Cadence Cue
                - Audio cue to be played regularly through progression of a cadence frame
            - Cadence Cue Points
                - Normalized timing for when a given audio cue should be played during the duration of a cadence frame
                - This concept is especially important for exercises with asymmetric timing over the course of a cadence frame (Rowing)
