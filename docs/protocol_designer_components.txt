Suggested first-version behavior
    ProtocolModel owns phases and blocks.
    Every phase and block has a stable ID.
    All mutations happen through model methods.
    The model emits a generic change event.
    The UI rerenders the entire protocol pane after each change.
    The editor has normal, insert-phase, and insert-block modes.
    Insertion mode renders explicit insertion zones.
    Clicking a zone inserts the new item and exits insertion mode.
    Escape cancels insertion mode.
    Final JSON comes directly from the protocol model.
